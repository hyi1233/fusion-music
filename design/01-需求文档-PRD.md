# 01 · 需求文档（PRD）— G1 评审稿

## 一句话定位
**Fusion Music**：一个界面简洁的**动态歌词音乐播放器**——歌词是唯一的主角，音源是可插拔的免费听歌入口。

## 两大核心（产品存在的理由，其他一切为它们服务）
1. **动态歌词**：全屏逐字动画歌词（源自 Folia 开源引擎，AGPL-3.0），支持多种视觉样式，电视/手机上都是"歌词即背景"的沉浸体验。
2. **可添加的音源**：兼容洛雪（lx-music）音源脚本生态。用户可自行**添加 / 启用 / 禁用 / 删除**音源脚本，实现免费听歌。**软件不内置任何写死的音源归属，浏览内容永远跟随当前音源。**

## 关键需求（编号 R1–R8）
| # | 需求 | 说明 |
|---|------|------|
| R1 | 音源管理 | 添加洛雪脚本（URL 导入或本地文件导入）、启用/禁用、删除、查看音源状态与能力 |
| R2 | 能力声明制 | 每个音源声明其能力：搜索 / 排行榜 / 歌单 / 歌词 / 音质档位；界面按能力渲染，缺失即隐藏 |
| R3 | 源驱动浏览 | 排行榜/歌单的内容**完全由当前音源返回**（榜单名、数量、层级都随源变）；切换音源 = 整个浏览世界切换 |
| R4 | 搜索 | 按当前音源（或多源聚合）搜索歌曲，遥控器与触屏都可操作 |
| R5 | 播放与队列 | 播放/暂停/上下曲/ seek/音量；播放队列可见可管理 |
| R6 | 动态歌词 | 全屏逐字歌词动画，多种视觉样式，可切换；有歌词能力才显示歌词，无则优雅降级 |
| R7 | 双端形态 | Android TV（遥控器 D-pad 为第一交互）+ 手机（触屏）；同一 APK 自适应 |
| R8 | 简洁 | 首屏直达"听歌"；无广告、无登录墙、无社交模块 |

## 目标设备与场景
- **电视**：客厅遥控器听歌看歌词（核心场景）；待机氛围（歌词动画常驻）。
- **手机**：个人听歌，触屏滑动，歌词沉浸页。

## 非目标（明确不做）
- 不做账号系统、社交、评论、商城。
- 不内置破解任何平台 VIP（音源能力由用户添加的脚本自行决定，软件保持工具中立）。
- 不做桌面端（Web/Electron）——首版聚焦 Android（TV+手机）。

## 成功标准（用户验收口径）
1. 添加一个洛雪音源脚本 → 立即能用该源搜索并完整播放（非试听）。
2. 切换音源 → 排行榜界面整体变为该源的榜单集合。
3. 播放任意歌曲 → 全屏逐字动态歌词正确滚动，电视遥控器全程可操作。
