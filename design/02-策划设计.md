# 02 · 策划设计 — G2 评审稿

## 一、参考分析（站在巨人肩膀上）

### 洛雪音乐 lx-music-mobile（学"听歌骨架"）
已核实源码（/tmp/lxmm）：
- **音源 = 动态脚本**：`core/userApi.ts` 的 `importUserApi(script)` → `loadScript()`，音源以脚本形式添加/删除/启用，软件本体不含任何源。
- **排行榜跟随源**：`core/leaderboard.ts` → `musicSdk[source].leaderboard.getBoards()` / `getList(bangId, page)`——**每个源返回自己的榜单集合**（如酷狗有 TOP500/新歌榜/飙升榜，网易有云音乐新歌榜/原创榜……名字与数量完全不同），UI 只渲染源返回的内容。
- **源选择器**：`components/SourceSelector.tsx`——下拉切换，列表由 `setSourceList(list, activeSource)` 动态注入。
- **首页视图结构**：`Home/Views/` = Leaderboard（排行榜）/ SongList（歌单）/ Mylist（我的收藏）/ Search / Download / Setting，横竖屏双布局。
- 启发：我们的浏览层直接采用"**源 → 源返回的栏目集合**"模型，UI 做通用容器。

### Folia folia-major（学"歌词灵魂与外观"）
- 播放页 = **全屏动态歌词即背景**，控制条极简半透明，其余界面全部让位给歌词。
- 暗色底 + 发光渐变文字；歌词样式可切换（多个 visualizer 模式）。
- 启发：设计语言定为"**歌词是唯一的光源**"——所有 chrome 藏进黑暗，只有歌词与焦点发光。

## 二、信息架构（IA）

```
┌ 首屏（二选一，设置里记住用户偏好）
│   TV: 浏览页   手机: 浏览页
├─ 浏览页 Browse ──┐ 顶部：当前音源徽标（点击/按菜单键 → 音源管理）
│                  ├ 栏目页签：由当前源返回（如 酷狗→[排行榜|歌单|推荐]；网易→[排行榜|歌单]）
│                  ├ 排行榜列表 → 榜单详情（分页 30 条）
│                  └ 歌单列表 → 歌单详情
├─ 搜索页 Search ── 搜索框 + 结果列表（当前源；后续可扩展聚合）
├─ 播放页 Play ──── 全屏动态歌词 + 底部控制条 + 队列入口（左右滑出）
├─ 音源管理 Sources ─ 音源列表（启用开关/能力徽标/状态）+ 添加（URL/本地文件）+ 删除
└─ 设置 Settings ─── 音质档位 / 歌词样式 / 首屏偏好 / 关于
```

全局：底部（TV）或底部导航（手机）三入口——**浏览 / 搜索 / 播放**；音源管理与设置为二级页。

## 三、音源数据模型（v2，按洛雪真实机制修正）

> 洛雪的真实结构：**添加"洛雪"这一个音源后，里面自带酷狗/网易/QQ/酷我/咪咕全部平台**；点击某个平台，主页才显示该平台的样子（它自己的排行榜/歌单）。音源脚本（自定义 API）负责提供这些平台的播放链接。

```ts
/** 平台：音源内部的子频道（酷狗/网易/QQ/酷我/咪咕...） */
interface Platform {
  id: string                    // 'kugou' | 'netease' | 'qq' | 'kuwo' | 'migu' | ...
  name: string
  capabilities: {
    search: boolean; boards: boolean; songlist: boolean; lyric: boolean
    qualities: string[]         // ['128k','320k','flac']
  }
}
/** 音源：一个可添加的实体（内置=洛雪生态；自定义=用户脚本），内含平台集合 */
interface SourceInfo {
  id: string; name: string; version: string
  status: 'ok' | 'initing' | 'error'
  platforms: Platform[]         // ← 换音源=换一整套平台世界
}
```

- **主页两级结构**：顶部选平台（酷狗/网易/QQ...）→ 主页内容 = 该平台的排行榜/歌单/推荐（完全由平台返回，UI 只做容器）。
- **换音源 = 换一整套平台集合**（如某脚本只支持 3 个平台，则平台选择器只显示 3 个）。

## 四、用户故事（验收主线）

| # | 故事 | 涉及界面 |
|---|------|----------|
| U1 | 作为用户，我在电视上开机直达浏览页，按方向键选中当前音源的"新歌榜"，Enter 后整页 30 首入队播放 | Browse |
| U2 | 作为用户，我按菜单键打开音源管理，用屏幕键盘/手机端输入 URL 添加洛雪脚本，看到能力徽标点亮 | Sources |
| U3 | 作为用户，我把音源从酷狗切到网易，浏览页页签与榜单整体变为网易的（云音乐新歌榜/原创榜…），带滑动转场 | Browse |
| U4 | 作为用户，播放时全屏逐字歌词动画滚动，按 OK 呼出控制条，按返回只隐藏控制条不退出应用 | Play |
| U5 | 作为用户，我左右滑（手机）或左右键（TV）在 浏览/搜索 间切换，滑动跟手 | 全局 |
| U6 | 作为用户，音源脚本失效时看到状态徽标变红 + toast 提示，不影响其他功能 | Sources/全局 |

## 五、功能清单（优先级）

**P0（首版必须）**：音源添加/删除/启用（R1）、能力声明（R2）、源驱动排行榜+歌单浏览（R3）、搜索（R4）、播放+队列（R5）、全屏逐字歌词（R6）、TV 遥控器全键位（R7）。
**P1（首版尽量）**：多源聚合搜索、我的收藏（本地）、歌词翻译行、桌面歌词。
**P2（后续版本）**：下载、音色/均衡器、皮肤主题市场。
