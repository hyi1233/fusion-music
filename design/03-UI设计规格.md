# 03 · UI 设计规格 — G3 评审稿

> 设计语言：**灯夜 Lumen Night**——歌词是唯一的光源。深空黑底，唯一强调色为极光青（与歌词光谱同族）；界面元素平时隐入黑暗，被焦点或播放唤醒时发光。
> 主题令牌单一来源：`design/system/theme.ts`（实现阶段禁止硬编码色值）。
> **动态原型**：`design/prototype/index.html`（单文件，浏览器直接打开），本规格所有界面与交互均可在原型中操作体验。

## 全局规格

- **导航结构**：TV 端左侧竖排导航（浏览/搜索/播放/音源/设置，焦点在导航与内容区左右切换）；手机端底部三 Tab（浏览/搜索/播放）+ 二级页。
- **遥控器键位（全局）**：↑↓ 移动焦点；←→ 页内横移/切页签；OK(Enter) 确认；菜单键 → 音源管理；返回键 → 关弹层/退一级/退后台（双击退出）；长按 OK → 歌曲更多操作。
- **焦点规格**：`focus.ring` 4px 极光青描边 + 6px 外发光 + 1.06 倍缩放，120ms。
- **转场**：页面横切 220ms out-expo（体现"滑动感"）；弹层上浮 420ms；切源时浏览区内容做 220ms 横向滑出→滑入。
- **状态枚举（每个列表/页面必须齐备）**：加载（呼吸点）、空（引导文案）、错误（含重试）、正常。

## S1 浏览页 Browse（首屏，两级结构：音源 → 平台 → 平台内容）
- **布局**：顶部一行 = 平台选择器（**音源内部的平台集合**：酷狗 / 网易 / QQ / 酷我 / 咪咕…胶囊横排，当前平台高亮发光）+ 音源徽标（点击 → 音源管理）；主体 = 当前平台的栏目页签（**由平台返回**）与其内容。
- **排行榜区**：平台返回的榜单卡片列表（榜单名 + 歌曲数 + 更新时间，每平台不同）；Enter → 榜单详情（30 条/页，↑↓选歌，OK 播放）。
- **切平台/切音源**：平台胶囊 ←→ 直接切（内容区 220ms 横滑）；音源徽标 OK → 音源管理（含添加音源）。
- **验收清单**：
  - [ ] 同一音源内点击不同平台 → 主页整体变为该平台的样子（页签、榜单集合、命名全部不同）
  - [ ] 换音源 → 平台选择器集合变化（音源覆盖几个平台就显示几个）
  - [ ] 无 boards 能力的平台不显示排行榜页签
  - [ ] 方向键全程可完成：切平台→进榜单→选歌→播放
  - [ ] 加载/空/错误三态齐备

## S3 播放页 Play（灵魂页——必须嵌入真实 Folia 视觉引擎）
- **布局**：**全屏动态歌词 = Folia VisualizerStage 真实引擎**（星象/雾笺/町景/hanabi 等十余种全屏视觉模式，粒子/着色器动画，非 CSS 文字动画）；顶部半透明歌曲信息（淡入 3s 隐去）；底部控制条常暗，方向键唤起，8s 隐去。
- **歌词**：逐字时间轴驱动 Folia 引擎（当前行逐字点亮 + 全屏背景随乐句流动变化）；样式切换 = Folia 的 visualizer 模式循环（Tab 键），每个模式都是完整的全屏动画场景。
- **验收**：[ ] 视觉效果与 Folia 同级（全屏动画场景，可演示至少 3 种模式差异明显）；[ ] 逐字点亮与音频对齐（误差 < 150ms）；[ ] 控制条唤起/隐去流畅；[ ] 返回键不退出应用。

## 端适配规格（G3 新增，否决"网页缩放感"）
- **TV/平板（横屏 ≥1024px）**：左侧竖排导航；内容区大间距、行高 88px、字号按 10-foot 规则（type 令牌原值）；焦点环+发光；遥控器键位。
- **手机（<768px）**：无左侧导航，底部三 Tab；单列列表；字号 ×0.75；触屏滑动、无 hover 态；安全区（刘海/手势条）。
- **原型要求**：两套布局是真实重排（DOM 结构不同），不是 viewport 缩放。

## S4 音源管理 Sources（本产品核心差异页）
- **布局**：音源列表（名称+版本+能力徽标[搜索|榜单|歌单|歌词]+状态灯：绿 ok/黄 initing/红 error）；顶部"＋ 添加音源"。
- **添加流程**：弹层两选一（输入脚本 URL / 本地文件导入）→ 解析预览（显示脚本声明的能力）→ 确认添加 → 列表出现并默认启用。
- **行内操作**：启用/禁用开关；删除（二次确认）；TV 上长按 OK 弹操作菜单。
- **验收**：[ ] 添加 URL 成功并立即可用；[ ] 能力徽标与实际能力一致；[ ] 禁用后浏览页立即移除该源；[ ] 删除有二次确认。

## S5 设置 Settings（轻量）
- 音质档位（随源能力显示可选档）；歌词样式选择（带缩略动图预览）；首屏偏好；关于（版本/开源致谢：Folia · lx-music）。

## S6 队列 Queue（播放页内抽屉）
- 右侧滑入（TV：播放页按 → 至队列入口 OK；手机：左滑）；当前曲目高亮，↑↓ OK 跳播；支持移除单曲。

## 原型演示脚本（评审路径）
1. 打开 `design/prototype/index.html` → 默认 TV 浏览页（酷狗源）。
2. 方向键移动焦点 → OK 进榜单 → 播放 → 全屏歌词逐字点亮。
3. 按菜单键 → 音源管理 → 添加音源（输入 URL）→ 能力徽标点亮。
4. 切换源为"网易" → 浏览页整体滑变为网易榜单集合。
5. 右下角"TV / 手机"开关 → 查看手机布局（底部 Tab、触屏滑动）。
